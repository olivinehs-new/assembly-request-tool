# 국회 자료요구서 문항 목록 생성

원문 PDF에서 문항을 분리해 프로젝트 최상위의 `split.py`와 `data/문항목록.csv`를 만든다. 교체된 문항목록이 있으면 그 파일을 정답 예시로 삼아 코드의 출력 형식을 맞춘다.

## 먼저 확인할 것

1. 프로젝트의 `AGENTS.md`, `CONTEXT.md`, `PROGRESS.md`와 `처리지침.md` 제2장을 읽는다.
2. `원문/*.pdf`, 기존 `split.py`, `data/문항목록.csv`의 열·인코딩·값 표기를 확인한다.
3. `pypdf` 설치 여부를 먼저 확인한다. 없으면 `pip install pypdf`를 보여 주고 사용자 허락을 받은 뒤 설치한다.
4. 교체된 `data/문항목록.csv`가 있으면 절대 덮어쓰지 말고 회귀 검증용 정답으로 보존한다.

## 만들어야 하는 코드

- 프로젝트 최상위에 `split.py` 하나만 만든다. PDF 처리는 `pypdf`만 사용하고, 표준 라이브러리의 `csv`, `re`, `pathlib`는 사용할 수 있다.
- 원문 PDF를 수정하지 않는다.
- 열 순서는 `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`로 고정한다.
- CSV는 `utf-8-sig`와 `newline=""`로 쓴다.
- 기존 출력 파일을 임의로 덮어쓰지 않는다. 사용자가 새 파일 생성을 요청했을 때만 지정 경로에 쓴다.
- 이 프로젝트에서는 [assets/split.py](assets/split.py)를 출발점으로 복사하거나 필요한 범위만 조정한다.

## 추출과 표기 규칙

1. 첫 줄의 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 추출한다.
2. `수신:` 줄에서 제출기한을 찾아 `YYYY-MM-DD`로 저장한다.
3. `수신:`, `담당 보좌관:`, `끝.`은 문항에 넣지 않는다. 이름과 연락처도 저장하지 않는다.
4. 줄 맨 앞의 `숫자.`를 새 문항으로 본다.
5. `가.`, `나.` 등은 세부항목에 넣고 항목이 여러 개면 한 셀에서 ` / `로 연결한다. 항목 표시는 유지한다.
6. `※` 줄은 비고에 넣되, CSV에는 `※`와 뒤 공백을 빼고 내용만 저장한다. 비고가 여러 개면 ` / `로 연결한다.
7. 그 밖의 줄은 바로 앞에서 활성화된 요구내용·세부항목·비고에 공백 한 칸으로 이어 붙인다.
8. 페이지 경계를 없애고 전체 줄 순서로 처리한다. 다음 페이지 첫 줄의 비고가 앞 페이지 마지막 문항에 붙을 수 있다.

## 교체본과 회귀 검증

교체된 `data/문항목록.csv`가 있으면 `split.py`의 파싱 함수를 메모리에서 실행해 다음을 비교한다. 정답 CSV를 삭제·이름 변경·덮어쓰기 하지 않는다.

- 열 이름과 순서
- 행 수와 파일별 행 수
- 모든 행의 순서
- 모든 셀의 문자열 값
- UTF-8 BOM 여부

현재 프로젝트 예시는 78행이며, 기존 코드와 교체본의 차이는 세부항목 구분자와 비고의 `※` 제거에 집중되어 있다. 숫자만 맞추지 말고 셀 값의 차이가 0건이어야 완료다.

## 최종 확인

- 파일별로 `파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)`를 제시한다.
- 일치가 X이거나 기준 CSV와 다른 셀이 있으면 원인을 고치고 다시 검사한다.
- 세부항목과 비고가 모두 있는 문항 3개를 원문과 결과로 나란히 대조한다.
- CSV 전체에서 보좌관 이름, 연락처, `담당 보좌관`, `수신:`이 저장되지 않았는지 확인한다.
- 바뀐 파일과 검사 결과를 `PROGRESS.md`에 기록한다.
